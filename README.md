# Sabor & Afeto

A mobile-first front-end project developed as a digital menu and ordering experience for a fictional/small confectionery business.

The project was designed specifically for mobile devices, focusing on a simple and practical ordering flow.

## Technologies

- HTML5
- CSS3
- JavaScript

## Features

- Product catalog
- Category filtering
- Product detail modal
- Shopping cart
- Quantity and total calculation
- Promotional pricing rules
- Side navigation menu
- WhatsApp order integration

## Design

This project follows a mobile-first approach and was primarily designed for smartphone screens rather than desktop use.

## Status

Completed as a front-end study project.
